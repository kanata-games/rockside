# ROCKSIDE – 海音の冒険

海音（うみね）が杖のショットで進む、ドット絵の横スクロールアクションゲームです。ブラウザだけで遊べます（スマホ対応）。

**プレイ:** https://kanata-games.github.io/rockside/

## 遊び方

タイトルのあとに **ステージセレクト**（3×3）が出ます。友だちが影に染まった「DARK」ボスとして待っています。倒すと元に戻って仲間になります。
- いま遊べるのは次の5エリアです（残り3マスは準備中）。
  - エリア1「夕焼けの丘」… DARK 飛梅
  - エリア2「月影の森」… DARK ネーニア
  - エリア3「夜曲の街」… DARK 青天
  - エリア4「星導の聖堂」… DARK アスターテ
  - エリア5「災厄の紅月城」… 魔王ディザスター（スターさん）
- 助けた友だちは、ほかのステージで手伝ってくれます（ネーニア：援護射撃、青天：回復の歌、アスターテ：道案内とチェックポイント）。
- クリアしたエリアにはチェックが付き、進み具合はブラウザに保存されます。
- 外側の8エリアをすべてクリアすると、中央の最終エリアが開きます。
- 進み具合を消すには、タイトル画面右上の「ERASE DATA」を2回タップします（キーボードは Delete を2回）。

## 操作方法

### スマホ（タッチ）
- 画面左下のボタン：左右に移動
- 画面右下のボタン：ジャンプ / ショット
- タップでスタート・リトライ
- 縦持ち・横持ちのどちらでも遊べます

### キーボード
| 操作 | キー |
|---|---|
| 移動 | ← → / A D |
| ジャンプ | Z / Space / K |
| ショット | X / J |
| スタート・リトライ・決定 | Enter |
| ステージセレクトのカーソル | ← → ↑ ↓（タッチは左右ボタンか、マスを直接タップ） |
| ステージセレクト → タイトル | Esc |
| 音のオン/オフ | M |

## キャラクターについて

登場キャラクター（海音、飛梅、ネーニア、青天、アスターテ）は作者の友人たちのキャラクターです。キャラクターの権利はそれぞれの持ち主に帰属します。無断での転載・二次利用はご遠慮ください。

## エリア5：災厄の紅月城（試作）

- ステージ選択の上段中央から入れます。
- 錬金剣の剣・槍・弓を切り替えて攻撃。HP半分以下で攻撃間隔が短くなります。
- 撃破後は正常なスターさんに戻り、クリア記録を保存します。
- 現段階のゲーム用素体は48×48／32×32の仮SVG素材です。制作中のイラスト版アニメーションへの差し替えは未完了です。
- ボス戦直前から試す場合：`?area=5&boss=1`（ダメージを受けずに確認する場合は `&god=1` を追加）。
