# ROCKSIDE – 海音の冒険

海音（うみね）が杖のショットで進む、ドット絵の横スクロールアクションゲームです。ブラウザだけで遊べます（スマホ対応）。

**プレイ:** https://kanata-games.github.io/rockside/

## 操作方法

### スマホ（タッチ）
- 画面左下のボタン：左右に移動
- 画面右下のボタン：ジャンプ / ショット
- タップでスタート・リトライ
- 縦持ち・横持ちのどちらでも遊べます

### キーボード
| 操作 | キー |
|---|---|
| 移動 | ← → / A D |
| ジャンプ | Z / Space / K |
| ショット | X / J |
| スタート・リトライ | Enter |
| 音のオン/オフ | M |
